# 💰 Sweden Gender Pay Gap Analysis

## 📌 Overview
This project analyzes the gender pay gap in Sweden using real data 
from SCB (Statistics Sweden) API. We compare average monthly 
salaries between men and women in 2023-2024.

## 🔍 Key Findings
- Men average salary 2024: 43,800 SEK
- Women average salary 2024: 39,300 SEK
- Gender pay gap 2023: **10.0%**
- Gender pay gap 2024: **10.3%**
- The gap is **growing** — not shrinking!

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- SCB PxWeb API (real government data)

## 📊 Data Source
Statistics Sweden (SCB) — National Mediation Office  
https://www.scb.se
